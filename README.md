# Brote
Brote es un e-Commerce de plantas, ornamentales y servicios de paisajismo.

Proyecto Final desarrollado para el Curso Front-End JS de Talento Tech, de la Agencia de Habilidades para el Futuro, propuesta de 'Buenos Aires Aprende'.

El proyecto utiliza HTML5, CSS3 Y JavaScript vanilla.

---
## Requisitos de pre-entrega del Proyecto Práctico.
- Una pagina index.html, como pagina principal, con los productos de la tienda.
- Una pagina contacto, dentro de la carpeta "pages" con un formulario de contacto (pueden utilizar el de "formspree").
- Carpeta css con el archivo styles.css.
- Carpeta img para las imagenes a utilizar.

Se deben utilizar etiquetas semanticas en la medida que se pueda.
Los estilos deben estar enlazados por un archivo externo. 
⛔No se debe utilizar css inline ni la etiqueta `<style> `dentro del `head`.

Se debe haber aplicado al menos flex como forma de posicionamiento para lograr que el sitio se vea bien, sin desbordes, tanto en pantallas grandes como chicas (utilizar el inspector del navegador para ir achicando la pantalla y ver cómo acomodan las tarjetas para evitar el desborde cuando no entran).

Ambos links (repositorio + github pages) deben ser copiados y pegados en el espacio de entrega.
NO SE DEBEN CARGAR ARCHIVOS NI CARPETAS EN EL CAMPUS.
